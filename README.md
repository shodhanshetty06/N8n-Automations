# N8n-Automations

Reusable n8n automation workflows for email and productivity tasks.

## About

This repository contains n8n workflows that automate repetitive tasks. Current workflows are organized by use case.

## Workflow Collection

- Gmail Automation

## Requirements

- n8n installed (local or cloud)
- Valid credentials for connected services (for example Gmail OAuth)
- Any required API keys or environment variables

## How to Use

1. Open n8n.
2. Import the workflow JSON from this repository.
3. Configure credentials and required variables.
4. Test each node.
5. Activate workflow.

## Best Practices

- Do not commit secrets, tokens, or credentials.
- Keep workflow names descriptive.
- Add notes and comments inside complex workflows.
